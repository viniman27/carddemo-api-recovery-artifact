# Revisão independente PT-BR da campanha oficial large12k

Este diretório contém uma auditoria fora-para-dentro da interpretação dos resultados em `P3/official-campaign-large12k-run-v2/campaign-report.json`, sem alteração de APIs, execuções, suites congeladas ou artefatos originais.

Arquivos:

- `counterinterpretation-and-limitations-ptbr.md` — relatório interpretativo principal.
- `quantified-evidence.json` — agregações programáticas derivadas do relatório oficial e das suites congeladas v3.
- `case-audit-extract.csv` — uma linha por caso executado, com status, classificação estrutural, admissibilidade, hashes e excertos decodificados.
- `decoded-samples.json` — uma amostra por combinação experimento/condição/status/classe de resposta.
