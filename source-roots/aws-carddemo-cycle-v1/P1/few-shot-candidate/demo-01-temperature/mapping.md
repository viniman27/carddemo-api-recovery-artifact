# Mapeamento observável

- Inputs/outputs COBOL mapeiam ao corpo e resposta 200.
- Uma transformação → um POST.
- Ambiguidade: arredondamento/overflow HTTP não definidos.
- Proveniência: sintético, não derivado de casos avaliados, caso institucional ou E3.

O domínio de entrada representável pode produzir resultado fora de PIC S9(3)V99. O exemplo não define resposta HTTP para overflow; isso permanece lacuna explícita, não comportamento COBOL verificado.
